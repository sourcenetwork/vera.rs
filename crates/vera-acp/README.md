# vera-acp

Access-control policy interfaces, policy YAML parsing and permission-engine
types used by Vera. The library defines the policy surface; applications supply
the storage and execution environment.

## Installation

```toml
[dependencies]
vera-acp = "0.1.2"
```

See the [API documentation](https://docs.rs/vera-acp) and
[Vera repository](https://github.com/sourcenetwork/vera.rs) for details.
