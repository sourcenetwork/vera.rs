# vera-crypto

Cryptographic types and utilities used by Vera, including BLS, secp256k1,
Ed25519 and P-256 identity handling, token verification and threshold-signature
support.
Applications are responsible for key management and configuring trusted
identities.

## Installation

```toml
[dependencies]
vera-crypto = "0.1.2"
```

See the [API documentation](https://docs.rs/vera-crypto) and
[Vera repository](https://github.com/sourcenetwork/vera.rs) for details.
