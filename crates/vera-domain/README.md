# vera-domain

Shared Vera domain types for blocks, transactions, consensus, membership and
state commitments. These types are used by the client, verifier and node
components.

## Installation

```toml
[dependencies]
vera-domain = "0.1.2"
```

See the [API documentation](https://docs.rs/vera-domain) and
[Vera repository](https://github.com/sourcenetwork/vera.rs) for details.
