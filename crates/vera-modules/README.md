# vera-modules

Types and module logic for Vera access control, bulletin records, validator
membership and threshold-service rings. This crate provides module building
blocks; it does not run a Vera node.

## Installation

```toml
[dependencies]
vera-modules = "0.1.0"
```

See the [API documentation](https://docs.rs/vera-modules) and
[Vera repository](https://github.com/sourcenetwork/vera.rs) for details.
